## Build/style

- C++23 project.
- Core static library name: `emw`.
- Eigen is used for linear algebra.
- OpenMP is required by the core build.
- OpenBLAS/BLAS is enabled through `EIGEN_USE_BLAS`.
- Tests use GoogleTest; benchmarks use Google Benchmark.

## Operator namespaces

Surface-related code includes `EMW::OperatorK`, `EMW::OperatorR`, and
`EMW::Helmholtz` helpers.

Volume code uses `EMW::Operators::Volume::operator_K_over_cube_mesh`.

Do not normalize namespace/style names as part of a mathematical change unless
refactoring is explicitly requested.

## Critical sign detail

`EMW::Helmholtz::V(k,x,y)` is documented as MINUS `grad_x G`.

The mathematical project operator is

`R[j] = int grad_x G cross j`.

Therefore any use of `Helmholtz::V` inside R must be checked together with the
cross-product order. Add a regression test before relying on it.

## Volume mesh

`EMW::Mesh::VolumeMesh::CubeMesh` stores a Cartesian parallelepiped grid with
`dx`, `dy`, `dz` and flattened cube index

`cx + nCx*(cy + nCy*cz)`.

The class name says `CubeMesh`, but the general constructor can represent
rectangular voxels. Confirm whether each operator implementation actually
supports `dx != dy != dz` before advertising that capability.

## Volume K discretization

The current `operator_K_over_cube_mesh` contains:

- dense Galerkin assembly;
- triple-Toeplitz assembly;
- custom block-size/permutation variants;
- ACA-compressed internal blocks;
- near/self singularity extraction;
- arbitrary-point field evaluation.

The implementation separates the project K operator into:

1. a `k^2` volume Green-potential contribution;
2. a face/surface contribution generated by jumps of PWC vector components
   across voxel faces.

This is an important existing design pattern. Reuse and test it rather than
adding a second incompatible voxel K implementation.

## Structured matrices

Existing aliases include `ToeplitzBlock`, `ToeplitzToeplitzBlock`,
`TripleToeplitzBlock`, and corresponding factored-block variants.

Prefer these abstractions for CPU Toeplitz work unless a new FFT-specific
storage layer has a demonstrated performance or API reason.
